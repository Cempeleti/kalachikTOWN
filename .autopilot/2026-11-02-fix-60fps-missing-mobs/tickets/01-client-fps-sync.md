# 01 — Синхронизация client.fps и конфигурации 60 FPS

**Требования:** R01, R03i, R06i
**Blocked by:** —
**Зона:** `code/modules/client/`, `code/game/`, `code/controllers/`
**Волна:** 1
**Status:** ready

## Что должно заработать

1. При подключении игрока к серверу с 60 FPS его client.fps автоматически равен 0 (синхронизация с world.fps) или не меньше world.fps, предотвращая пропуск кадров и исчезновение мобов на клиенте.
2. При смене FPS сервера через `world.change_fps(new_fps)` все подключенные клиенты (`GLOB.clients`) немедленно обновляют свой client.fps.
3. В `preferences.dm` значение `clientfps` по умолчанию равно 0 (синхронизация). Сохраненные предпочтения со старым значением 20 принудительно обновляются, если они ниже `world.fps`.
4. В `code/controllers/configuration/entries/general.dm` дефолтное значение FPS обновлено до 60, чтобы Master Controller при инициализации не сбрасывал 60 FPS обратно до 20.

## Из брифа, дословно

> «почему пропали персонажи ... при постановке 60 фпс до этого было 20»

## Разделы спецификации

Пользовательские истории 1, 4, 7; Решения §1, §4; Швы §1.

## Критерии приёмки

- [ ] `clientfps` по умолчанию равен 0 (sync).
- [ ] В `client/Login()` значение `client.fps` защищено от установки значения меньше `world.fps`.
- [ ] В `world/proc/change_fps()` обновляются все клиенты в `GLOB.clients`.
- [ ] Дефолтное значение конфигурации `/datum/config_entry/number/fps` установлено в 60.
- [ ] Код компилируется без синтаксических ошибок.
