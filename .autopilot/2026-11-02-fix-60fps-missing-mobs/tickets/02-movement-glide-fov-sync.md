# 02 — Масштабирование движения (glide_size) и синхронизация FOV/SSincone при 60 FPS

**Требования:** R01.1, R02, R04i, R05i
**Blocked by:** 01
**Зона:** `code/__DEFINES/`, `code/modules/mob/`, `code/controllers/subsystem/processing/`
**Волна:** 2
**Status:** completed

## Что должно заработать

1. Макрос `DELAY_TO_GLIDE_SIZE` в `code/__DEFINES/movement.dm` не зажимает glide_size в устаревшие рамки 4..8 (которые создавали 3-кратное ускорение и замирание анимации на 60 FPS). Минимальный glide_size равен 1 (или 0 при отсутствии задержки), максимальный равен `world.icon_size` (32).
2. Подсистема `SSincone` в `code/controllers/subsystem/processing/incone.dm` получает флаг `SS_TICKER`, чтобы обрабатывать обновление оверлея моба на верхнем плане каждый тик без задержки в 6 тиков (100 мс).
3. При входе в игру в `Login()` (`code/modules/mob/living/login.dm`) вызывается инициализация конуса и оверлея (`update_vision_cone()` / `update_cone()`), чтобы персонаж не появлялся скрытым за маской `GAME_PLANE_FOV_HIDDEN`.

## Из брифа, дословно

> «почему пропали персонажи и тд при постановке 60 фпс до этого было 20 и тд»

## Разделы спецификации

Пользовательские истории 2, 3, 5, 6; Решения §2, §3; Швы §2, §3.

## Критерии приёмки

- [x] `MIN_GLIDE_SIZE` и `MAX_GLIDE_SIZE` в `movement.dm` масштабированы корректно для произвольного FPS/tick_lag (включая 60 FPS).
- [x] `DELAY_TO_GLIDE_SIZE(2)` при 60 FPS дает ~2.67 px/тик и не срывается в 4.
- [x] `SSincone` снабжена флагом `SS_TICKER`.
- [x] `mob/living/Login()` инициализирует визуал конуса и оверлей собственного персонажа.
- [x] Код компилируется без ошибок.
